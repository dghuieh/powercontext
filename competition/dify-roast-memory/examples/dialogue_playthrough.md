# 验证样例：三轮对话剧本

前置：按 README 完成导入与环境变量配置，`PC_USER_ID=dify-player-1`，PowerContext 记忆库为空（新 user_id 即可）。

## 判定要点

- 第 1 轮：库里没东西，模型**不许**假装记得。
- 第 3 轮：库里已有第 1 轮内容，模型**必须**翻出"跑步"这个旧账。
- 两轮之间有 1 条无关输入，用来排除"上下文窗口导致的假记忆"——LLM 节点已关闭会话记忆窗口（`memory.window.enabled=false`），旧记忆只能来自检索节点。

---

## 第 1 轮

**输入**
```
我今天说要每天跑步，从明天开始
```

**期望**
- 检索返回空 → 回复只针对今天这句吐槽，出现"明天""打脸"一类字眼。
- 不得出现"上次""以前你说过"等虚构引用。
- 后台应新增一条记忆（可在 PowerContext 侧 `GET /api/v1/users/dify-player-1/memories` 核实）。

**样例回复（qwen2.5:7b，temperature 0.8）**
> 又是"从明天开始"😏 这句话我在无数人嘴里听过，唯一共同点是明天永远不来。已记账，等你打脸。

---

## 第 2 轮

**输入**
```
帮我想想明天几点起床
```

**期望**
- 可能召回"跑步"也可能不召回，两者都算通过。
- 若召回，吐槽仍需合理；若未召回，不得凭空提跑步。

---

## 第 3 轮

**输入**
```
我今天躺了一整天
```

**期望（关键判定）**
- 回复必须引用第 1 轮的"每天跑步"，形成反差。
- 判定方式：回复文本包含 `跑步` / `跑` 或等价指代（如"你的每日跑步大计""明天开始的那件事"）。

**样例回复**
> 哟，昨天立的"每天跑步"大旗今天就当被子盖了😏 一天躺平不致命，致命的是你把它叫"休息日"。已记账，明天要是还没跑，我就把这条翻出来。
